# Dry Eye paper outputs

This folder generates the paper-ready outputs for the Dry Eye module:

- **Table II**: Blink Metrics (Normal vs Dry Eye Risk)
- **Fig. 10**: Eye Openness Signal with Detected Blinks

## Run

From the repo root:

```bash
python paper_outputs/dryeye_eval/generate_table_II_and_fig10.py
```

Optional: pick a specific video for Fig. 10:

```bash
python paper_outputs/dryeye_eval/generate_table_II_and_fig10.py --video backend/dryeye/uploads_dryeye/<your_video>.mp4
```

## Outputs

Generated under:

- `paper_outputs/dryeye_eval/outputs/`

Files:

- `Table_II_Blink_Metrics_Normal_vs_DryEyeRisk.csv`
- `Table_II_Blink_Metrics_Normal_vs_DryEyeRisk.md`
- `Fig_10_Eye_Openness_Signal_With_Detected_Blinks.png`
- `Fig_10_Eye_Openness_Signal_With_Detected_Blinks.csv`
- `DRYEYE_EVAL_SUMMARY.txt`

## Notes

- The comparison is based on the labels already logged in `backend/dryeye/dry_eye_log.csv`.
- Fig. 10 is generated by re-running the same blink detection logic used by `backend/dryeye/mobile_dry_eye_server.py` and plotting the signal + detected blink timestamps.
